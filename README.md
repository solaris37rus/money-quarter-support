# Денежный квартал — поддержка

Это страница поддержки мобильной игры «Денежный квартал».

Если нашли ошибку или хотите предложить улучшение, [создайте обращение](https://github.com/solaris37rus/money-quarter-support/issues/new) (потребуется аккаунт GitHub). Опишите модель телефона, версию Android, шаги воспроизведения и ожидаемое поведение. Не публикуйте пароли, контакты и другие личные данные.

Игровые рубли не являются настоящими деньгами: их нельзя вывести или обменять.
